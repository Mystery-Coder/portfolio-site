# 🌐 Portfolio Site

A modern, responsive personal portfolio website showcasing projects, skills, and experience. Built with **React** and **Vite** for optimal performance and development experience.

## 🌍 Live Site

Visit my portfolio: [srikar.is-a.dev](https://srikar.is-a.dev)
ALso, run
`bash
curl -L srikar.is-a.dev
`

## 📋 Features

- **Responsive Design** - Works seamlessly on desktop, tablet, and mobile devices
- **Dark Mode Support** - Toggle between light and dark themes for optimal viewing comfort
- **Project Showcase** - Display and showcase your best work with detailed descriptions
- **Skills Section** - Highlight technical skills and expertise
- **Contact Information** - Easy-to-use contact section for reaching out
- **About Me** - Personal introduction and background information
- **Fast Performance** - Built with Vite for lightning-fast load times
- **Modern UI** - Clean, professional design with smooth interactions
